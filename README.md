# Maze

Maze is the example application of the [Orcraft tutorial](https://orcraft.app/tutorial/maze-application/): a small program that stands in for the system under test while the tutorial builds its test suite against it.

This repository holds the Maze releases. It contains no source code.

## Download

Each release on the [releases page](https://github.com/GMCoreAI/orcraft-maze-app/releases) provides one executable per operating system: `maze-<version>-win.exe` for Windows, `maze-<version>-linux` for Linux and `maze-<version>-macos` for macOS. The tutorial says which versions it needs and where to put them.

On Linux and macOS, make the downloaded file executable before running it:

```
chmod +x maze-<version>-linux
```
